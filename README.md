# AlphaMan

**AI 하이라이트 쇼츠 자동 제작(알파컷) + AI 자막 편집기·디스커버리(픽셀링)** 를 하나로 통합한 플랫폼입니다.
**웹사이트 버전**과 **프로그램(데스크톱) 버전** 두 가지로 제공되며, 두 버전은 같은 코어(`packages/core`)와 같은 UI(`apps/web`)를 공유하므로 모든 기능이 양쪽에 동일하게 들어 있습니다.

기능 목록 전체와 원본(alphacut.video / app.pixeling.io) 대응표는 [FEATURES.md](./FEATURES.md) 를 보세요.

## 바로 사용하기

| 버전 | 링크 |
|---|---|
| 🌐 **웹사이트 버전** | **https://alphaman.vercel.app** (설치 없이 브라우저에서 바로) |
| 💻 **프로그램(PC) 버전** | **https://github.com/myzxit/AlphaMan-/releases/latest** — Windows `.exe`(설치형/포터블), macOS `.dmg`(Apple Silicon/Intel), Linux `.AppImage`/`.deb` |

> 웹사이트 버전(Vercel)은 서버리스 데모라 데이터가 인스턴스마다 휘발됩니다(관리자 계정은 항상 로그인 가능). 영구 데이터가 필요하면 아래 Docker/VPS 방식으로 직접 호스팅하세요.
> 프로그램 버전은 코드 서명 전이라 Windows SmartScreen 은 "추가 정보 → 실행", macOS 는 앱 우클릭 → "열기" 로 실행합니다.

## 빠른 시작

```bash
npm install            # 워크스페이스 링크 + (선택) Anthropic SDK, Electron
npm run web            # 웹사이트 버전 → http://localhost:4100
npm run desktop        # 프로그램 버전 (Electron 창이 열리고 내장 서버가 127.0.0.1 에서 실행)
npm test               # 코어 + API 테스트 (12개)
npm run check          # 전체 JS 구문 검사
npm run desktop:build  # Windows(.exe/portable) · macOS(.dmg) · Linux(.AppImage/.deb) 설치 파일 생성 → release/
docker compose up -d   # 자체 호스팅 (영구 데이터 볼륨 /data, ffmpeg 포함) → http://localhost:4100
```

## 배포 · 릴리스

- **웹사이트**: `vercel.json` + `api/index.js` 로 Vercel 에 배포됩니다(`main` 푸시 시 자동). 다른 서버에서는 `Dockerfile`/`docker-compose.yml` 또는 `npm run web` 을 사용하세요.
- **PC 설치 파일**: `v*` 태그를 푸시하면 GitHub Actions(`.github/workflows/release.yml`)가 Windows/macOS/Linux 러너에서 설치 파일을 빌드해 GitHub Release 에 첨부합니다. 수동 실행은 Actions 탭의 "Release (PC 설치 파일)" → Run workflow.
- **CI**: `.github/workflows/ci.yml` 이 푸시/PR 마다 구문 검사와 테스트를 실행합니다.

Node.js 20.10 이상이 필요합니다. 외부 런타임 의존성은 없습니다(저장소는 JSON 파일, 서버는 Node 내장 `http`).

## AI 재구성 · 내 목소리 TTS

- **AI 재구성 (`#/remix`)**: 영상 링크 또는 파일 하나를 올리면 원본의 박힌 자막·효과음·배경음을 걷어내고, 목표 길이(1~28분)에 맞춰 AI 가 구간을 선별·재배열한 뒤 새 자막(템플릿)·효과음 큐·배경음악·전환·색보정을 입혀 다시 구성합니다. 참고 유튜브 링크를 넣으면 그 영상의 호흡·자막 스타일·구조·톤·효과음 밀도를 분석해 같은 방식으로 재구성합니다. 결과는 편집(제목·자막·효과음)과 다시 만들기(이용권 50%)가 가능하고 MP4/ASS/JSON 으로 내보냅니다.
  - 작업 생성 시 **"내가 직접 제작했거나 사용 허가를 받은 영상"** 확인이 필요합니다. 타인의 영상을 무단으로 재가공하는 용도는 지원하지 않으며, 플랫폼의 저작권 판정 결과를 보장하지 않습니다.
- **내 목소리 TTS (`#/voice`)**: 아무 말이나 녹음한 목소리 샘플(5초 이상, 30초 이상 권장)을 올려 음성 프로필을 만들면, 쇼츠 스튜디오의 "AI 후킹 보이스"와 AI 재구성의 내레이션(오프닝·마무리 / 전체)을 내 목소리로 읽어줍니다. 본인 목소리(또는 허가받은 목소리) 확인이 필요합니다.
  - 실제 음성 파일 생성: `ELEVENLABS_API_KEY` 설정 또는 로컬 Coqui XTTS(`tts` CLI) 설치. 둘 다 없으면 합성 계획만 생성됩니다.

## 무료 TTS 목소리 · 구독 CTA · 유튜브 최적화 · 썸네일

- **무료 TTS 목소리 26종** (`#/voice`): 한국어 기본 9종(선희·인준·현수·봉진·국민·지민·서현·순복·유진) + 스타일 변형 10종(뉴스·동화 낭독·다큐·쇼츠 빠르게·광고·속삭임·스포츠 중계·예능·강의·힐링) + 영어/일본어/중국어 7종. 목소리마다 **▶ 듣기**로 바로 들어보고, 쇼츠 "AI 후킹 보이스"와 AI 재구성 내레이션에서 고를 수 있습니다. 실제 MP3 파일은 ① `edge-tts` CLI(`pip install edge-tts`) ② 내장 Edge TTS(네트워크) ③ Google 읽어주기(네트워크, 언어당 1 목소리) 순서로 되는 엔진이 만들고, 모두 안 되면 브라우저/OS 내장 음성(Web Speech API, 오프라인)으로 재생합니다. 만들어진 음성 파일은 계정 저장소(Vercel Blob)에 보관되어 미리보기·렌더링에 쓰입니다.
- **미리보기에서 TTS 재생·원본 자막 가리기**: 타임라인 미리보기는 후킹 보이스/내레이션을 시점에 맞춰 재생하고(TTS 중 원본 소리 줄임, 전체 내레이션이면 원본 소리 끔), 원본에 박힌 자막 제거 옵션이 켜져 있으면 렌더 계획과 같이 화면 하단을 잘라 원본 자막이 보이지 않게 합니다. 효과음·배경음의 실제 제거와 원본 영상 재인코딩은 `ffmpeg`(+`demucs`, `yt-dlp`)가 있는 프로그램 버전·자체 호스팅에서 이루어집니다 — 유튜브 링크도 `yt-dlp` 로 내려받아 실제 MP4 를 렌더링하고 TTS 를 섞습니다.
- **내 목소리 프로필 저장**: 샘플을 올려 만든 프로필은 계정에 저장되고(웹사이트 버전은 샘플 파일도 Vercel Blob 에 보관) **▶ 샘플 듣기 · 내 목소리로 문장 읽기**로 확인할 수 있습니다.
- **영상 마무리 구독 카드**: 쇼츠 클립과 AI 재구성 결과의 끝에 "구독 · 좋아요 · 알림 설정" CTA 카드가 자동으로 들어갑니다(문구 수정·끄기 가능). 미리보기에 구독 버튼 화면으로 표시되고, ffmpeg 렌더 시 실제 종료 화면으로 이어 붙습니다.
- **유튜브 최적화 (📈)**: 클립·재구성·롱폼마다 원본 제목·태그·대본을 바탕으로 **원본과 거의 비슷한 제목**, 유튜브 추천(홈·쇼츠 피드·검색)에 유리한 **최고 추천 제목 후보 5개(점수)**, 설명, 태그 15개, 해시태그 3개, 추천 업로드 시간, 알고리즘 체크리스트를 만듭니다. 클릭 한 번으로 복사. AI 키가 있으면 AI 가, 없으면 규칙 엔진이 만듭니다.
- **썸네일 자동 제작 (🖼️)**: 완료 즉시 자동으로 만들어집니다. 유튜브 원본이면 **원본 썸네일과 거의 비슷하게**(원본 구도 + 큰 텍스트), 아니면 후킹·핵심 문장·유튜브 프레임(25/50/75%)·ffmpeg 프레임 중 점수가 높은 장면을 골라 텍스트·그라데이션·배지를 입힙니다. 편집기에서 장면 선택, 영상에서 직접 캡처, 이미지 올리기, 문구·스타일(원본 비슷하게/큰 텍스트/숫자 강조/컬러 밴드/미니멀)·색상 변경, PNG/SVG 저장이 가능합니다. 보관함 썸네일에도 반영됩니다.

## 보관함 · 미리보기 · 원본과 똑같은 자막

- **보관함 (`#/library`)**: 쇼츠 · AI 재구성 · 롱폼 컷편집이 완료되면 자동으로 저장됩니다. 종류/즐겨찾기/검색으로 찾고, ▶ 미리보기 · MP4 저장 · SNS 업로드 · 이름 변경 · 제거가 가능합니다. 대시보드에도 "최근 만든 영상"이 표시됩니다.
- **미리보기 플레이어**: 완성된 영상을 바로 확인합니다. 렌더된 MP4 가 있으면 그대로 재생하고(Range 스트리밍으로 탐색 가능), 없으면 원본(유튜브 IFrame / 업로드·로컬 파일)을 새 타임라인(원본 구간 · 리플레이 · 슬로모션 · 챕터 카드)대로 이어 재생하면서 자막 · 첫 3초 후킹 · 카드를 겹쳐 보여줍니다. 쇼츠 클립 카드, 재구성 결과 페이지(인라인), 롱폼 결과, 보관함 어디서나 열 수 있습니다.
- **원본 대본 그대로 (자막 = 원본 스크립트)**: 추정 대본은 만들지 않습니다. 대본은 다음 중 하나로만 확보됩니다.
  1. 파일/컴퓨터 영상: **브라우저에서 Whisper(transformers.js)** 로 원본 음성을 그대로 받아 적어 서버로 보냅니다 (처음 한 번 모델 다운로드, tiny/base/small 선택). 업로드와 동시에 진행되며 결과를 확인·수정할 수 있습니다.
  2. 링크: 유튜브 **"...더보기 → 스크립트 표시"** 에서 복사한 대본을 붙여넣습니다 (유튜브 스크립트 복사본 · SRT · `[mm:ss] 문장` · 문장만 모두 지원). 프로그램 버전과 `yt-dlp` 가 있는 서버는 링크의 자막을 자동으로 가져옵니다.
  3. 서버에 `whisper` CLI 가 있으면 서버에서 직접 받아 적습니다.
  - 대본을 구하지 못하면 작업을 만들지 않고 안내(422)로 실패하며 이용권은 차감되지 않습니다. 결과에는 "원본 대본 그대로" 배지가 표시됩니다. (`ALPHAMAN_ALLOW_SIMULATED_STT=1` 은 테스트·데모 전용)

## 선택적 연동

| 기능 | 없을 때 | 있을 때 |
|---|---|---|
| `ANTHROPIC_API_KEY` (또는 `ant auth login`) | 규칙 기반 엔진으로 하이라이트/번역/주제 추천/픽시 응답 | `claude-opus-5` 로 실제 AI 처리 (`@anthropic-ai/sdk`) |
| `ffmpeg` / `ffprobe` | 길이 추정 + 렌더 계획(JSON) | 실제 메타데이터 추출, 파형, MP4 클립 렌더링 |
| `whisper` CLI | 브라우저 Whisper(파일) / 붙여넣은 대본(링크) 사용 | 서버에서 직접 음성 인식(STT) |
| `yt-dlp` | oEmbed 로 제목/썸네일만, 링크 대본은 붙여넣기 | 유튜브 길이·채널·챕터 조회 + 링크의 원본 자막(대본) 자동 가져오기 |
| `ELEVENLABS_API_KEY` 또는 `tts`(Coqui XTTS) | 내 목소리 합성 계획만 | 실제 음성 클론 TTS 파일 생성 |
| `edge-tts` (`pip install edge-tts`) | 무료 목소리를 브라우저/OS 내장 음성으로 재생 | 무료 목소리 26종 MP3 파일 생성 (렌더링에 포함) |
| `demucs` | 효과음/배경음 제거 계획 | 음원 분리로 목소리만 남기고 효과음·배경음 실제 제거 |

환경 변수: `PORT`(기본 4100), `HOST`, `ALPHAMAN_DATA_DIR`(데이터 폴더), `ALPHAMAN_AI=off`(AI 강제 비활성), `ALPHAMAN_WHISPER_MODEL`.

## 프로그램 버전 전용 기능

- 컴퓨터/USB 드라이브의 MP4 를 업로드 없이 바로 열기 (쇼츠 스튜디오 · 자막 편집기의 "컴퓨터/USB 영상" 탭)
- USB 드라이브 자동 검색 (Windows/macOS/Linux)
- 로컬 ffmpeg/Whisper 로 오프라인 렌더링·음성 인식, `yt-dlp` 자동 설치(첫 실행 시 사용자 데이터 폴더에 내려받아 링크의 원본 자막을 자동으로 가져옴)
- 컴퓨터/USB 영상도 브라우저 Whisper 로 원본 대본을 추출하고, 미리보기 플레이어가 로컬 파일을 바로 재생
- 시스템 트레이, OS 알림(작업 완료·문의 답변), 앱 메뉴(데이터/출력 폴더 열기)
- `ALPHAMAN_SCREENSHOT=경로` 로 무인 스모크 테스트(화면 캡처 후 종료)
